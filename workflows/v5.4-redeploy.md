# 重新部署 AuditCertificate.sol 到 Sepolia

## 步骤

### 1. 重新部署 AuditCertificate
```bash
cd /root/projects/glm-code
export PRIVATE_KEY="你的私钥"
export SEPOLIA_RPC_URL="https://ethereum-sepolia-rpc.publicnode.com"

forge script script/DeployCertificate.s.sol \
  --rpc-url $SEPOLIA_RPC_URL \
  --private-key $PRIVATE_KEY \
  --broadcast
```

### 2. 记录新合约地址
从 broadcast 输出中提取新部署的合约地址。

### 3. 更新前端合约地址
把 `frontend/app.js` 中的 `NFT_CONTRACT` 改为新地址。

### 4. 重新铸造测试 NFT
```bash
cast send <新合约地址> "mintTest(address,uint8)" 0x7b5538AAd3b048bAe0EFF2b457C59B8FE98032B8 1 \
  --rpc-url $SEPOLIA_RPC_URL \
  --private-key $PRIVATE_KEY
```

### 5. 验证 uri() 返回 SVG
```bash
cast call <新合约地址> "uri(uint256)(string)" 1 --rpc-url $SEPOLIA_RPC_URL
```
确认返回值包含 `data:image/svg+xml;base64,`。

### 6. 更新 README/PLAN 中的合约地址
把旧地址 `0x636B3Af9630e1b26b02BA488a5b8Ab6cE75d6721` 替换为新地址。

### 7. 提交推送
```bash
cd /root/projects/glm-code && git add -A && git commit -m "deploy: redeploy AuditCertificate with uri() fix" && git push origin master
```
