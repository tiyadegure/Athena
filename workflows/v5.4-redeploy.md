# 重新部署 AuditCertificate 到 Sepolia

## 背景
uri() 修复后需要重新部署合约。旧合约无法返回 NFT metadata。

## 步骤

### 1. 编译确认
```bash
cd /root/projects/glm-code && forge build
```

### 2. 部署新版合约
```bash
export PRIVATE_KEY="<你的 Sepolia 私钥>"
export SEPOLIA_RPC_URL="https://rpc.sepolia.org"

forge script script/DeployCertificate.s.sol \
  --rpc-url $SEPOLIA_RPC_URL \
  --broadcast \
  --private-key $PRIVATE_KEY
```

### 3. 铸造测试 NFT
```bash
# 用部署脚本输出的新合约地址
export NFT_CONTRACT="<新合约地址>"

cast send $NFT_CONTRACT \
  "mintTest(address,uint8)" \
  0x7b5538AAd3b048bAe0EFF2b457C59B8FE98032B8 1 \
  --rpc-url $SEPOLIA_RPC_URL \
  --private-key $PRIVATE_KEY
```

### 4. 验证 uri() 返回 metadata
```bash
cast call $NFT_CONTRACT \
  "uri(uint256)(string)" 1 \
  --rpc-url $SEPOLIA_RPC_URL
```

应该返回包含 `data:image/svg+xml;base64,...` 的 JSON 字符串。

### 5. 更新前端
```bash
# 更新 frontend/app.js 中的 NFT_CONTRACT 地址
# 更新 demo/report.json 中的合约地址
```

### 6. 更新文档
更新以下文件中的合约地址：
- README.md
- PLAN.md
- AGENTS.md
- demo/report.json

### 7. 提交
```bash
git add -A && git commit -m "feat: redeploy AuditCertificate with uri() metadata support" && git push origin master
```
