# 修复 uri() 返回空字符串

## 问题
AuditCertificate.sol 的 `uri()` 硬编码返回 `""`，OpenSea/Etherscan 无法显示 NFT 图像。

## 修改文件

### 1. contracts/AuditCertificate.sol

**添加状态变量**（在 trait 数据结构之后）：
```solidity
mapping(uint256 => bytes32) public tokenAttestation;
```

**修改 mintCertificate()**（约 line 115）：
铸造成功后添加：
```solidity
tokenAttestation[tokenId] = attestationUID;
```

**修改 mintTest()**（约 line 93）：
铸造成功后添加：
```solidity
tokenAttestation[tokenId] = bytes32(uint256(uint160(to)));
```
用 to 地址生成一个伪 attestationUID，这样每个测试铸造也有唯一 SVG。

**修改 uri()**（约 line 201）：
- 从 `pure` 改为 `view`
- 读取 `tokenAttestation[tokenId]`
- 如果非零：调用 `generateMetadata(attestationUID, tokenId)` 返回
- 如果为零：返回一个默认的 metadata JSON（含默认 traits 的 SVG）

```solidity
function uri(uint256 tokenId) public view override returns (string memory) {
    require(tokenId >= GOLD && tokenId <= BRONZE, "Invalid token ID");
    bytes32 attUID = tokenAttestation[tokenId];
    if (attUID != bytes32(0)) {
        return generateMetadata(attUID, tokenId);
    }
    // Fallback: default metadata for tokens without attestation
    TraitData memory defaultTraits = TraitData({
        helmet: 4,  // 经典
        shield: 4,  // 空白
        color: 2,   // 铜
        weapon: 0,  // 长矛
        background: 0, // 星空
        eyes: 0,    // 蓝
        rarityScore: 50
    });
    string memory svg = _generateAthenaSVG(tokenId, defaultTraits);
    string memory tierName;
    if (tokenId == GOLD) tierName = unicode"A 级 (Gold)";
    else if (tokenId == SILVER) tierName = unicode"B 级 (Silver)";
    else tierName = unicode"C 级 (Bronze)";

    return string(
        abi.encodePacked(
            '{"name":"Athena Audit Certificate #0",',
            '"description":"', tierName, ' - Rarity: 50/100",',
            '"image":"data:image/svg+xml;base64,', Base64.encode(bytes(svg)), '"}'
        )
    );
}
```
