# Senior Auditor's Mindset

## 1. The Feynman test
Can you explain what this function does to someone who doesn't know Solidity?

## 2. Socratic questioning
For every line: why is this here? What does it assume? What happens if the assumption breaks?

## 3. Inversion
After understanding what code IS supposed to do, ask: how would I make it NOT do that?
