The Problem

Smart contract security audits are slow, expensive, and unverifiable.

Human audits take 2-4 weeks and cost $50,000+. AI tools can only detect single vulnerabilities, not complete attack chains.

There's no way to verify the audit process or results on-chain.

The Solution

Athena uses GLM-5.1's long-horizon task capability to complete an 8-step audit pipeline in a single session.

From vulnerability discovery to on-chain certification, everything is automated and verifiable.

AI Agent autonomously audits, generates PoC, runs fuzz tests, and mints NFT certificates.

8-Step Audit Pipeline

01

Contract Analysis

Parse contract source code, identify functions, state variables, and inheritance hierarchy.

protocol_scanner
02

Dual-Engine Static Analysis

Run Slither and Aderyn in parallel for comprehensive vulnerability detection.

slither_runner aderyn_runner
03

RAG Knowledge Enhancement

Query ChromaDB knowledge base for similar vulnerability patterns and historical exploits.

knowledge_base
04

PoC Generation

Auto-generate Foundry test contracts that prove vulnerabilities are exploitable.

poc_generator exploit_simulator
05

Fuzz Testing & Formal Verification

Run Foundry fuzz tests (256 runs) and Halmos symbolic execution for mathematical proof.

fuzz_runner halmos_runner
06

Repair & Validation

Generate fix suggestions, apply patches, re-audit to verify vulnerabilities are resolved.

repair_validator incremental_auditor
07

On-Chain Certification

Submit audit results to Ethereum Attestation Service (EAS) for immutable on-chain record.

eas_attest evidence_chain
08

NFT Certificate Minting

Mint S/A/B/C tier generative Athena NFT (262,144 combinations) with on-chain SVG.

AuditCertificate ERC-1155
