# Athena PPT 素材

## PPT 文件
- `Athena-Hackathon.pptx` — 黑客松演示文稿（10 页）

## 生成脚本
- `generate-ppt.js` — Node.js 脚本，使用 pptxgenjs 生成 PPTX
- 运行：`node ppt-assets/generate-ppt.js`
