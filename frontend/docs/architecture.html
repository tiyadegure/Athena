Athena — System Architecture

Athena is built on a layered architecture where GLM-5.1 serves as the reasoning engine, coordinating specialized agents and tools through MCP (Model Context Protocol).

Layer 1 — LLM Reasoning

GLM-5.1

Long-horizon reasoning engine. Maintains context across the entire 8-step audit pipeline. Understands multi-contract interactions and cascading vulnerabilities.

  • Context window: 128K tokens
  • Long-horizon task capability (key differentiator)
  • Coordinates all agents and tools
Layer 2 — Audit Skill

12 Specialized Agents

Domain-specific audit skill with 12 agent roles, each focused on a specific security domain.

  • Reentrancy Detector
  • Flash Loan Analyzer
  • Access Control Auditor
  • Oracle Manipulation Checker
  • Gas Optimization Advisor
  • And 7 more specialized roles...
Layer 3 — MCP Tools

13 Security Analysis Tools

Tools accessible via Model Context Protocol, enabling GLM-5.1 to perform deep security analysis.

  • slither_runner — Static analysis
  • aderyn_runner — Rust-based analysis
  • halmos_runner — Symbolic execution
  • fuzz_runner — Fuzz testing
  • poc_generator — PoC test generation
  • exploit_simulator — Attack simulation
  • protocol_scanner — Multi-contract analysis
  • repair_validator — Fix verification
  • incremental_auditor — Incremental audits
  • evidence_chain — Audit evidence
  • eas_attest — On-chain attestation
  • knowledge_base — Vulnerability patterns
  • gev_analyzer — MEV/GEV analysis
Layer 4 — On-Chain

Smart Contracts

On-chain components for verification and certification.

  • AuditCertificate.sol — ERC-1155 NFT with on-chain SVG
  • AuditEvidenceChain.sol — Audit evidence storage
  • Ethereum Attestation Service (EAS) — Immutable audit proof
  • Sepolia testnet deployment

Data Flow

Input: Solidity source code → Analysis: GLM-5.1 + Agents + MCP Tools → Output: JSON Report + EAS Attestation + ERC-1155 NFT
