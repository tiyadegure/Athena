ATHENA — Documentation

1. Product & Strategy

Athena is an AI-powered smart contract security audit agent built on GLM-5.1's long-horizon reasoning capabilities.

Target Market

ToB/B2B: DeFi protocols, DAO treasuries, NFT projects, and L2 bridges.

Key Differentiators

  • Long-horizon reasoning: Multi-step audit workflows (8+ sequential steps)
  • On-chain certification: ERC-1155 NFT certificates with 262,144 unique trait combinations
  • Agent economy: Autonomous audit → certification → future trading
  • 12 specialized audit agents + 13 MCP tools

2. Architecture

8-step audit workflow from contract analysis to on-chain NFT certification.

1. Contract Analysis → 2. Vulnerability Detection → 3. PoC Generation → 4. Multi-Contract Audit → 5. Repair Validation → 6. Evidence Chain → 7. EAS Attestation → 8. NFT Mint

Core Components

  • Audit Skill: 12 specialized agents for different audit phases
  • MCP Tools: 13 tools for security analysis, PoC generation, and on-chain verification
  • ERC-1155 NFT: S/A/B/C tier system with 262,144 trait combinations
  • EAS Integration: On-chain attestation for audit results

3. Audit Workflow

Complete audit flow from contract analysis to on-chain NFT certification.

Phase 1: Analysis

  • Contract parsing and AST analysis
  • Function and state variable identification
  • Inheritance hierarchy mapping

Phase 2: Detection

  • Slither/Aderyn static analysis
  • Halmos symbolic execution
  • Custom vulnerability patterns

Phase 3: Verification

  • PoC generation and testing
  • Multi-contract interaction analysis
  • Repair validation

Phase 4: Certification

  • Evidence chain recording
  • EAS on-chain attestation
  • ERC-1155 NFT minting

4. NFT Certificate System

Generative NFT certificates with S/A/B/C rarity tiers and 262,144 unique trait combinations.

Trait Dimensions (4^9 = 262,144)

  • Background: 4 variants
  • Body: 4 variants
  • Eyes: 4 variants
  • Headpiece: 4 variants
  • Wings: 4 variants
  • Accessory: 4 variants
  • Aura: 4 variants
  • Crown: 4 variants
  • Special: 4 variants

Rarity Tiers

  • S-TIER Rainbow gradient + dynamic glow (64 combinations)
  • A-TIER Gold gradient + crown (256 combinations)
  • B-TIER Silver gradient (1,024 combinations)
  • C-TIER Bronze base (259,800 combinations)
